## How to preview

## How to publish
Upload the contents of this folder to any static hosting service (for example, Netlify, Cloudflare Pages, GitHub Pages, or your web host).
Set the site's custom domain to `dreamescapetraveltours.com` after confirming the domain is active in your registrar account.

## Domain note
At the time the site package was prepared, a direct request to `https://dreamescapetraveltours.com` returned a 404 response. This usually means the domain exists but is not currently serving the intended website, or DNS/hosting is not connected correctly. Check the registrar's DNS records and hosting configuration before changing the domain.
